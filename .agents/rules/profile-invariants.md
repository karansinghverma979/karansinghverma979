## 🏛️ Core Principles & Invariants

### 1. 🛡️ Zero Secret & Sensitive Contact Exposure
- **No Private Tokens**: Strictly ban hardcoded bot tokens, private API keys, or machine-specific paths.
- **Private C2 Quarantine**: Personal Telegram handles or bot handles used for private C2 control must NEVER be exposed publicly on the profile.
- **Verified Public Channels Only**: Only list public developer links (Google Developer Profile, public email, verified GitHub projects).

### 2. ⚡ Live Artifact & Metric Accuracy
- **Zero Hallucinated Metrics**: Latency benchmarks, RAM footprints, and cold boot speeds must reflect verified empirical telemetry from production binaries.
- **Synchronous Project Links**: All repository links and release tags must point to live, existing repositories.

### 3. 🎨 High-Impact Visual Hierarchy
- **Terminal Aesthetics**: Maintain high-contrast cybernetic styling (ASCII terminal cards, typing SVGs, verified status badges).
- **Responsive Formatting**: Ensure markdown layouts render cleanly on both desktop monitors and mobile GitHub apps without line wraps or broken image badges.
